# 1단계 개선 테스트용 (stage1b_test) — ※ 실제 완성본과 별개

목적: **필라멘트 최소화**. 이전 1단계 부품 중 쓸 수 있는 건 그대로 쓰고, 바뀐 부품만 새로 출력해서 교체.

## 재사용 (다시 출력하지 않음)
| 부품 | 비고 |
|---|---|
| 카드 1장 홀더 | 결합 핀 위치를 1단계와 똑같이 맞춤 |
| 커팅 받침 바 | 비스듬한 칼날이 기존 홈(6mm) 안에 들어가도록 칼날 이동 거리를 맞춤 |
| ~~필라멘트 조립 핀~~ | 더 이상 필요 없음 |

## 새로 출력 — `stage1b_test_new_parts.3mf` (한 판, 14개)
| 부품 | 수량 | 출력 방향 |
|---|---|---|
| 커팅 유닛 v2 (본체) | 1 | 세워서 (그대로) |
| 패들 v2 | 1 | 패들 면이 바닥 |
| 받침판 프레임 v2 | 1 | 받침판 면이 바닥 |
| 높이 조절판 | 1 | 뒤집어서 (다리가 위) |
| 경사 밀대 | 1 | 세워서 |
| 스프링 속기둥 | 4 | 눕혀서 (돌기가 위) |
| 지그재그 스프링 | 4 | 세워서 (볼펜 스프링 대신) |
| PLA 대체 칼날 (90mm) | 1 | 바닥에 눕혀서 |

- 실제 출력 약 60~70g 예상 (정확한 값은 슬라이스 후 확인) · **서포트 끄기**
- PLA 칼날은 **동작 확인 · 절취선 있는 제품**용. 절취선 없는 제품을 실제로 자르려면 18mm 대형 커터날(90mm로 부러뜨림)이 필요
- 지그재그 스프링은 PLA라 오래 쓰면 힘이 약해질 수 있음. 볼펜 스프링(지름 4~5, 길이 30~35mm)이 생기면 바꿔 끼우면 됨

## 바뀐 점
- **볼록부 16mm 기준** → 누르는 거리 약 23.6mm
- **작두식 칼날**: 3° 비스듬히, 한쪽 끝부터 잘림
- **스프링 4개 (암수 홈)**: 본체 옆 겉기둥(암) + 속기둥(수). 돌기를 ㄱ자 홈에 넣고 돌리면 잠기고, 손 떼면 앞 벽에 걸림(멈춤 턱)
- **칸 간격 조절: 바닥 가운데 경사 밀대** — 오른쪽으로 밀면 올라감(칸 간격 작아짐), 왼쪽은 내려감. 3mm 밀 때마다 1mm, 딸깍 걸림. 바닥 눈금 24~36
- 핀 구멍 방식 · 톱니 방식 삭제
- 테스트용이라 **덮개 없음**, 스프링 기둥은 옆판 바깥에 붙음 (완성본에서는 덮개 + 기둥을 벽 안쪽으로)

## 조립
1. **높이 조절판**: 가로대 양 끝을 본체 뒤쪽 양 옆판 안쪽의 세로 홈에 맞춰 위에서 내려 넣기 (다리가 아래로)
2. **경사 밀대**: 본체를 뒤집어 바닥 가운데 홈에 밀대를 끼우기 (딸깍 팔이 뒤쪽). 경사 높은 쪽이 왼쪽
3. 다시 세우고 **받침판 프레임**을 앞에서 넣어 팔 아래면이 조절판 레일 위에 얹히게
4. **패들**의 비스듬한 홈에 PLA 칼날(또는 커터날)을 얇은 쪽이 바깥으로 오게 끼우기
5. 패들을 넣으면서 양쪽 귀의 작은 핀이 받침판 팔 앞쪽 갈래 홈에 아래에서 들어가게
6. **스프링 4개**: 겉기둥 안에 지그재그 스프링(또는 볼펜 스프링) → 속기둥 돌기를 위쪽 입구 홈에 맞춰 밀어 넣고 바깥쪽으로 90° 돌려 잠금 → 속기둥 네모 끝을 패들 모서리 구멍에 꽂기
7. **커팅 받침 바**(기존)를 홈이 앞을 보게 위에서 넣기
8. **카드 1장 홀더**(기존)를 위 핀 4개에 꽂기
9. 바닥 밀대를 눈금 **30**에 맞추고 카드를 넣어 테스트

## 테스트 체크
- [ ] 작두식 칼날로 한 번에 잘리는지 (커터날 / PLA 칼날 각각)
- [ ] 스프링 4개로 패들이 비틀리지 않고 돌아오는지, 멈춤 턱에 걸리는지
- [ ] 바닥 밀대가 딸깍딸깍 움직이고, 받침판 높이가 바뀌는지
- [ ] 다음 칸이 내려와 받침판에 앉는지

# 사선 고정 칼날 테스트 (stage1b_fixed) — 패들 칼날로 안 잘려서 방식 변경

칼날을 카드 뒤에 **12° 사선으로 고정**하고, 패들의 미는 바가 아래 칸을 뒤로 밀어 한쪽 끝부터 베는 방식. 조립 그림: `stage1b_fixed_assembly.png`

## 새로 출력 — `stage1b_fixed_new_parts.3mf` (한 판, 4개, 서포트 끄기)
| 부품 | 수량 | 출력 방향 |
|---|---|---|
| 칼날 받침대 (기존 커팅 받침 바 자리) | 1 | 뒤집어서 (날 홈 위 다리는 브리지) |
| 미는 바 패들 (귀·핀 없음) | 1 | 패들 판이 바닥 |
| 받침판 고정쇠 왼/오 | 2 | 옆으로 눕혀서 |

- 빼는 것: 기존 패들, 커팅 받침 바, PLA 칼날 · 나머지는 그대로
- 칼날: 18mm 커터날 끝 1마디 부러뜨려 85~92mm (실제 날 필요)
- 받침판은 이제 패들과 안 이어지고 고정됨 → 잘린 칸이 받침판 뒤로 밀려나 떨어짐 (테스트에선 본체 안쪽 바닥으로)
- 끝까지 누르면 미는 면 y=22.6, 칼날 오른쪽 끝 y=18.4 → 약 4mm 여유
