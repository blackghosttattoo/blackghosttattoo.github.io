# 1단계 개선 테스트용 (stage1b_test) — ※ 실제 완성본과 별개

목적: **필라멘트 최소화**. 이전 1단계 부품 중 쓸 수 있는 건 그대로 쓰고, 바뀐 부품만 새로 출력해서 교체.

## 재사용 (다시 출력하지 않음)
| 부품 | 비고 |
|---|---|
| 카드 1장 홀더 | 결합 핀 위치를 1단계와 똑같이 맞춤 |
| 커팅 받침 바 | 비스듬한 칼날이 기존 홈(6mm) 안에 들어가도록 칼날 이동 거리를 맞춤 |
| PLA 대체 칼날 (88mm) | 새 칼날 홈에도 들어감 |
| 커터날 · 볼펜 스프링 | 그대로 사용 |
| ~~필라멘트 조립 핀~~ | 더 이상 필요 없음 |

## 새로 출력 — `stage1b_test_new_parts.3mf` (한 판)
| 부품 | 수량 | 출력 방향 |
|---|---|---|
| 커팅 유닛 v2 (본체) | 1 | 세워서 (그대로) |
| 패들 v2 | 1 | 패들 면이 바닥 |
| 받침판 프레임 v2 | 1 | 받침판 면이 바닥 |
| 높이 조절판 | 1 | 뒤집어서 (다리가 위) |
| 경사 밀대 | 1 | 세워서 |
| 스프링 속기둥 | 4 | 눕혀서 (돌기가 위) |

- 부품 부피 합계(속 꽉 찬 기준) 약 97cm³ → 실제 출력 약 60~70g 예상 (정확한 값은 슬라이스 후 확인)
- **서포트 끄기** (모든 부품 서포트 없이 뽑히도록 방향 지정)
- 선택: `stage1b_test_zigzag_springs_optional.3mf` — 볼펜 스프링이 없을 때만 (지그재그 스프링 4개, PLA라 테스트용)

## 바뀐 점
- **볼록부 16mm 기준** → 누르는 거리 약 23.6mm
- **작두식 칼날**: 3° 비스듬히, 한쪽 끝부터 잘림
- **스프링 4개 (암수 홈)**: 본체 옆 겉기둥(암) + 속기둥(수). 돌기를 ㄱ자 홈에 넣고 돌리면 잠기고, 손 떼면 앞 벽에 걸림(멈춤 턱)
- **칸 간격 조절: 바닥 가운데 경사 밀대** — 오른쪽으로 밀면 올라감(칸 간격 작아짐), 왼쪽은 내려감. 3mm 밀 때마다 1mm, 딸깍 걸림. 바닥 눈금 24~36
- 핀 구멍 방식 · 톱니 방식 삭제
- 테스트용이라 **덮개 없음**, 스프링 기둥은 옆판 바깥에 붙음 (완성본에서는 덮개 + 기둥을 벽 안쪽으로)

## 조립
1. **높이 조절판**: 가로대 양 끝을 본체 뒤쪽 양 옆판 안쪽의 세로 홈에 맞춰 위에서 내려 넣기 (다리가 아래로)
2. **경사 밀대**: 본체를 뒤집어 바닥 가운데 홈에 밀대를 끼우기 (딸깍 팔이 뒤쪽). 경사 높은 쪽이 왼쪽
3. 다시 세우고 **받침판 프레임**을 앞에서 넣어 팔 아래면이 조절판 레일 위에 얹히게
4. **패들**에 커터날(또는 PLA 칼날)을 비스듬한 홈에 끼우기
5. 패들을 넣으면서 양쪽 귀의 작은 핀이 받침판 팔 앞쪽 갈래 홈에 아래에서 들어가게
6. **스프링 4개**: 겉기둥 안에 볼펜 스프링 → 속기둥 돌기를 위쪽 입구 홈에 맞춰 밀어 넣고 바깥쪽으로 90° 돌려 잠금 → 속기둥 네모 끝을 패들 모서리 구멍에 꽂기
7. **커팅 받침 바**(기존)를 홈이 앞을 보게 위에서 넣기
8. **카드 1장 홀더**(기존)를 위 핀 4개에 꽂기
9. 바닥 밀대를 눈금 **30**에 맞추고 카드를 넣어 테스트

## 테스트 체크
- [ ] 작두식 칼날로 한 번에 잘리는지 (커터날 / PLA 칼날 각각)
- [ ] 스프링 4개로 패들이 비틀리지 않고 돌아오는지, 멈춤 턱에 걸리는지
- [ ] 바닥 밀대가 딸깍딸깍 움직이고, 받침판 높이가 바뀌는지
- [ ] 다음 칸이 내려와 받침판에 앉는지
