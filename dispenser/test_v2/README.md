# 카트리지 디스펜서 테스트 v2 (기능 테스트 전용)

**테스트 목표**: 카드 1장(5칸)을 통째로 넣으면 → 아래로 내려오고 → 패들(푸시 버튼)을 누르면 맨 아래 칸이 잘려 떨어지고 → 손을 떼면 다음 칸이 내려와 대기하는지.

v1에서 4장 매거진 · 푸셔 · 가이드봉 · 뚜껑 · 연결 레일은 전부 뺐습니다.

- 크기: 약 11.3 × 14.2 × 18 cm
- 기준 치수: 실측 2개 제품 (A 80 · B 29.8 · C 67 · D 15.5 · E 16 · F 0.5 mm)

- 부품은 출력 방향으로 놓여 있음 (돌리지 말고 그대로)

| 부품 | 수량 |
|---|---|
| 18mm 대형 커터날 (88mm 정도로 부러뜨림) | 1 |
| 볼펜 스프링 (지름 4~5, 길이 25~35mm) | 2 |
| 1.75mm 필라멘트 조각 (약 12mm) | 4 (멈춤핀 2 + 간격 조절 핀 2) |

## 조립
1. 본체 앞 양옆 좁은 통로 맨 안쪽에 **볼펜 스프링** 넣기
2. 패들 칼날 홈에 **커터날** 끼우기 (날이 카드 쪽, 약 7.5mm 노출)
3. **받침판 프레임**(받침판 + 양쪽 팔)을 통로에 앞에서 밀어 넣기
4. **패들**을 넣고, 패들 양쪽 귀의 **숫자 30 구멍**과 팔 구멍을 맞춰 **필라멘트 핀** 꽂기 (양쪽)
5. 본체 옆면 작은 구멍(양쪽)에 **멈춤 핀** 꽂기
6. **앤빌**을 홈이 앞을 보게 위에서 끼우기
7. **폭 가이드**를 오른쪽 위 톱니에 걸기 → 카드 넣어보고 살짝 여유 있게 위치 맞추기

## 조절 방법
### 칸 간격 (24 ~ 36mm, 2mm 단위)
- 패들 양쪽 귀에 숫자(24·26·…·36)가 새겨진 구멍이 있음
- 핀을 빼고 → 받침판 프레임을 올리거나 내려서 → 원하는 숫자 구멍에 다시 꽂기 (**양쪽 같은 숫자**)
- 칸 사이 납작한 틈이 15mm 정도로 넓어서, 실제 간격과 ±4mm 정도 차이 나도 잘 잘림. 지금 제품(29.8mm)은 **30**에 두면 됨

### 카드 폭 (70 ~ 86mm, 2mm 단위)
- 오른쪽 폭 가이드를 위로 살짝 들어 → 옆으로 옮겨 → 톱니에 다시 내려놓기
- 카드가 걸리지 않고 살짝 여유 있는 위치로

## 테스트 체크리스트
- [ ] 카드가 위에서 넣었을 때 걸리지 않고 받침판까지 내려가는지
- [ ] 패들을 누르면 맨 아래 칸만 깔끔하게 잘리는지 (절취선 있는 / 없는 제품)
- [ ] 잘린 1개가 트레이로 떨어지는지
- [ ] 손을 떼면 남은 카드가 한 칸 내려와 받침판에 앉는지 (5칸 모두 반복)
- [ ] 누르는 힘, 빡빡하거나 헐거운 곳
