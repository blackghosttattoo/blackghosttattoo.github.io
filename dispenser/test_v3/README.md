# 카트리지 디스펜서 테스트 v3 (필라멘트 절약형)

v2와 기능은 같고(카드 1장 → 패들 누르면 1칸 컷팅 → 다음 칸 대기, 칸 간격·폭 조절), **재료를 크게 줄인** 버전입니다.

| | v2 | v3 |
|---|---|---|
| 본체 | 꽉 찬 블록 + 트레이 + 경사로 | 3mm 옆판 2장 + 연결대 (창 뚫음) |
| 부품 부피 합계 (속 꽉 찬 기준) | 약 765 cm³ | 약 141 cm³ (약 1/5) |
| 크기 (패들 포함) | 11.3 × 14.2 × 18 cm | 10.9 × 11.4 × 13 cm |
| 잘린 칸 | 트레이로 미끄러짐 | 본체 아래 **책상으로 바로 떨어짐** |

정확한 g 수는 Bambu Studio에서 슬라이스하면 바로 나옵니다.

## 파일
- `test_v3_all_parts.3mf` : 부품 5개 한 판 (본체 · 패들 · 받침판 프레임 · 앤빌 · 폭 가이드)
- `v3_overview.png` : 구조 그림
- `dispenser_test_v3.scad` : 원본 설계

## 출력
- PLA, 0.2mm, 벽 2~3줄, 채움 10~15%, **서포트 없음**
- 본체 위쪽 앞 가로대와 뒤판 아래쪽은 긴 브릿지라 밑면이 살짝 처질 수 있지만 기능에는 문제없음

## 필요한 것
- 18mm 대형 커터날 1장 (약 88mm로 부러뜨림)
- 볼펜 스프링 2개 (지름 4~5, 길이 30~35mm)
- 1.75mm 필라멘트 조각 4개 (멈춤핀 2 + 간격 조절 핀 2)

## 조립
1. 받침판 프레임(받침판 + 양쪽 팔)을 본체 앞에서 밀어 넣기
2. 양쪽 팔 뒤끝과 본체 안쪽 스프링 받침 사이에 **볼펜 스프링** 끼우기 (받침의 작은 핀에 꽂기)
3. 패들 칼날 홈에 **커터날** 끼우기 (날이 카드 쪽, 약 7.5mm 노출)
4. 패들을 넣고, 패들 양쪽 귀의 **숫자 30 구멍**과 팔 구멍을 맞춰 **필라멘트 핀** 꽂기
5. 본체 옆판 작은 구멍(양쪽)에 **멈춤 핀** 꽂기
6. **앤빌**을 홈이 앞을 보게 위에서 넣기 (양옆 턱에 얹힘)
7. **폭 가이드**를 위쪽 톱니에 걸기

## 조절
- **칸 간격** 24~36mm: 패들 옆 숫자 구멍에 핀 옮겨 꽂기 (양쪽 같은 숫자). 지금 제품은 30
- **카드 폭** 70~86mm: 폭 가이드를 들어서 옆으로 옮겨 톱니에 걸기

## 테스트 체크
- [ ] 카드가 받침판까지 걸리지 않고 내려가는지
- [ ] 패들 누르면 맨 아래 칸만 잘리는지
- [ ] 잘린 칸이 아래로 떨어지는지
- [ ] 손 떼면 다음 칸이 내려와 받침판에 앉는지 (5칸 반복)
