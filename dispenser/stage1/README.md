# 1단계 테스트 — 커팅 유닛 + 카드 1장 홀더

**확인할 것**: 카드 1장(5칸)을 넣고 → 패들을 누르면 맨 아래 칸이 잘리고 → 손을 떼면 다음 칸이 내려와 대기하는지.

## 단계 구성 (부품은 계속 재사용)
| 단계 | 추가 부품 | 확인할 것 |
|---|---|---|
| **1단계 (지금)** | 커팅 유닛 · 패들 · 받침판 프레임 · 커팅 받침 바 · 카드 1장 홀더 | 컷팅 + 다음 칸 내려옴 |
| 2단계 | 4장 매거진 + 미는 판 (카드 1장 홀더 대신 같은 핀에 꽂음) | 한 장 다 쓰면 다음 장이 앞으로 나와 이어지는지 |
| 3단계 | 폭 가이드 + 옆 모듈 연결 부품 (옆판 아래 구멍 사용) | 다른 폭 제품 · 여러 줄 연결 |

## 재료
- 부품 부피 합계(속 꽉 찬 기준): **약 100 cm³** (v3 141, v2 765)
- 모든 부품이 **서포트 없이** 뽑히도록 출력 방향까지 정해 둠 (회전하지 말고 그대로)
- 짧은 브릿지(최대 26mm) 몇 곳만 있음

## 출력
`stage1_cutting_test.3mf` 한 판 · PLA · 0.2mm · 벽 2~3줄 · 채움 10~15% · **서포트 끄기**

## 필요한 것
- 18mm 대형 커터날 1장 (약 88mm로 부러뜨림)
- 볼펜 스프링 2개 (지름 4~5, 길이 30~35mm)
- 1.75mm 필라멘트 조각 4개 (멈춤핀 2 + 간격 조절 핀 2)

## 조립
1. 받침판 프레임을 커팅 유닛 앞에서 밀어 넣기
2. 팔 뒤끝과 안쪽 스프링 받침(작은 핀) 사이에 볼펜 스프링 끼우기
3. 패들 칼날 홈에 커터날 끼우기 (날이 카드 쪽, 약 5.5mm 노출)
4. 패들을 넣고 양쪽 귀의 **30** 구멍과 팔 구멍을 맞춰 필라멘트 핀 꽂기
5. 옆판 작은 구멍(양쪽)에 멈춤 핀 꽂기
6. 커팅 받침 바를 홈이 앞을 보게 위에서 넣기 (양옆 턱에 얹힘)
7. 카드 1장 홀더를 위 핀 4개에 꽂기
8. 카드를 볼록한 면이 앞으로 오게 위에서 넣기 → 패들 누르기
