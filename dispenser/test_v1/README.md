# 카트리지 디스펜서 테스트 v1 (1라인 모듈)

> ⚠ 지금 파일은 **추정 치수** 기준 시안입니다. 실측 치수를 받으면 같은 이름으로 다시 만들어 드립니다.

## 파일
| 파일 | 내용 |
|---|---|
| `plate1_mechanism.3mf` | 하부 본체 · 패들(캐리어) · 앤빌 블록 · 받침판 → **먼저 이것만 출력해서 커팅 테스트** |
| `plate2_magazine.3mf` | 상부 매거진 · 뚜껑 · 푸셔 · 가이드봉 2개 → 커팅이 잘 되면 출력 |
| `dispenser_test_v1.scad` | 원본 설계 (OpenSCAD). 맨 위 `[실측 치수]`만 바꾸면 전체 재계산 |
| `make_3mf.py` | STL → 3MF 묶는 스크립트 |

모듈 크기(대략): 폭 86 × 깊이 175 × 높이 186 mm

## 출력 설정 (Bambu Studio, P2S)
- 3MF 열기 → "Bambu 프로젝트가 아님" 안내가 나오면 **예** (형상만 불러옴)
- 프린터: P2S 0.4 노즐 / 필라멘트: **Bambu PLA Basic** (또는 사용 중인 PLA)
- 레이어 0.2mm, 벽 3줄, 상하판 4~5층, 채움 15% (자이로이드)
- **서포트 없음** (모든 부품이 서포트 없이 뽑히게 방향을 잡아둠)
- 부품은 이미 출력 방향으로 놓여 있음. 회전하지 말고 그대로 출력

## 필요한 부품
| 부품 | 수량 | 용도 |
|---|---|---|
| 18mm 대형 커터칼 날 | 1장 | 칼날. 부러뜨려서 **길이 64~67mm**로 맞추기 |
| 볼펜 스프링 (지름 4~5, 길이 25~35mm) | 2개 | 패들 복귀 |
| 압축 스프링 (지름 6~8, 길이 50~60mm) | 2개 | 카드 미는 판 (2번 플레이트용, 없으면 생략하고 테스트 가능) |
| 1.75mm 필라멘트 조각 (약 12mm) | 2개 | 캐리어 빠짐 방지 핀 |
| 순간접착제 | 조금 | 받침판 · 가이드봉 고정 |

## 조립 (1번 플레이트 = 커팅 테스트)
1. 하부 본체 앞쪽, 양옆 좁은 통로 맨 안쪽에 **볼펜 스프링**을 하나씩 밀어 넣는다.
2. 캐리어(주황 패들) 칼날 홈에 **커터날**을 끼운다. 날 쪽이 뒤(카드 쪽), 약 8mm 튀어나오게. 헐거우면 마스킹테이프 한 겹.
3. 캐리어를 본체 앞에서 통로에 맞춰 밀어 넣는다.
4. 본체 옆면 앞쪽 작은 구멍(양쪽)에 **필라멘트 핀**을 꽂는다 → 캐리어가 빠지지 않음.
5. 위에서 **받침판**을 넣어 캐리어 양쪽 턱의 핀에 끼우고 순간접착제로 고정.
6. **앤빌 블록**을 홈이 앞(패들 쪽)을 보게 위에서 끼운다.
7. 테스트: 카드 1장을 **볼록한 면이 앞**으로 오게 위에서 넣어 받침판 위에 세운다 → 패들을 끝까지 누른다.

> ⚠ 칼날이 매우 날카롭습니다. 조립·테스트 중 손가락을 카드 투입구에 넣지 마세요.

## 테스트 후 알려주면 좋은 것
- 한 번에 깔끔하게 잘렸는지 (절취선 있는 제품 / 없는 제품 각각)
- 누르는 힘이 적당한지, 너무 뻑뻑한지
- 잘린 1개가 트레이로 잘 굴러 나오는지
- 손을 떼면 다음 칸이 받침판 위로 내려오는지
- 끼워지는 부분이 너무 빡빡하거나 헐거운 곳 (→ `clr` 값 조정)
